# Historical archive

This directory is a read-only-by-default historical research archive inherited from earlier project stages. It is not a second app, a current architecture, or an active set of developer instructions.

The live product is the Android application in `mobile/app`. The sole active delivery plan is `.ralph/FRIDAY_DELIVERY_PLAN.md`. Read `RESEARCH_CORPUS_RULES.md` before using any archived material.

Historical Jarvis-labelled specifications and reports are retained for provenance and possible algorithm extraction only. Their implementation claims, package names, server destinations, permissions, roadmaps and capability descriptions are not authoritative for Friday.
