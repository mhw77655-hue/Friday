# JARVIS PROJECT DIRECTIVE

This repository contains the JARVIS project.

JARVIS_BIBLE/ is the authoritative specification once it has been generated and validated.

CURRENT PHASE:

The JARVIS Bible does not yet exist.

The first task of the AI agent is therefore NOT to modify or build JARVIS.

The first task is to completely inspect and understand the existing repository and create the authoritative JARVIS Bible.

During Bible creation:

- Do not rewrite production code.
- Do not refactor production code.
- Do not delete production code.
- Do not implement speculative features.
- Do not modify architecture merely to make documentation easier.
- Do not claim a capability exists without evidence.
- Do not treat comments or documentation as proof that code works.

The repository itself is evidence.

Tests are evidence.

Build configuration is evidence.

Documentation is evidence.

Git history may be used as evidence.

When evidence conflicts, record the contradiction.

Every major capability must be classified as:

IMPLEMENTED
PARTIALLY_IMPLEMENTED
SCAFFOLD
PLANNED
BROKEN
UNKNOWN
CONTRADICTORY
DEPRECATED

The future JARVIS Builder will use JARVIS_BIBLE/ as its engineering specification.

Therefore the Bible must distinguish actual implementation from intended architecture.

Accuracy is more important than optimism.

After the Bible has been created, it must be validated against the repository before being treated as authoritative.
