The real answer, and it's a genuine field of neuroscience/AI research, not a metaphor: the leading unifying theory of how the brain coordinates everything — perception, memory, planning, movement, emotion — under one mechanism is the Free Energy Principle / Active Inference (Karl Friston). The core claim: every one of those subsystems is doing the exact same computation, in the exact same currency — minimizing the mismatch between an internal predictive model and actual sensory input. Medium Not different systems each doing their own thing and reporting to a manager — one shared objective (prediction error / "free energy") that perception, action, learning, and decision-making all reduce to. ResearchGate That's the actual algorithm behind "acting as one" — a shared currency every subsystem speaks, so nothing needs a translator to compare or combine them.
And that same mechanism is also the literal answer to the 20W question — it's not a separate fact, it's the same fact. Because brains operate under a strict 20-watt energy budget, they evolved sparse and predictive coding — minimizing costly neural activity while still catching what matters. arxiv Neurons fire only when something meaningful actually happens — computation is triggered by the event, not by a constant clock cycle. Eureka At any given instant, most of the brain is not running — it's already predicting correctly, so it stays quiet. Only the parts where reality diverges from prediction actually spend power. A brain scaled down to the size of a model like Llama 3 would need roughly 2 milliwatts — a single AAA battery could run it for a month arxiv — because it's not doing a full dense pass through everything on every tick, the way current LLMs do on every single token regardless of whether anything's surprising.
One honest caveat before I hand you the design implication: the full version of this (actual spiking neural networks on neuromorphic silicon — Loihi, TrueNorth) only gets you those real power numbers on specialized hardware. Run the same sparse spike-based algorithm on ordinary CPU/GPU and you lose most of the energy benefit, because the algorithm's sparse design doesn't match the processor's dense, clock-driven nature — your phone's Snapdragon isn't neuromorphic silicon. So literal SNNs aren't the buildable path here. But the principle — one shared prediction-error signal gating who spends compute at all — is 100% implementable in ordinary software, and it's the part that actually matters for "not overheating."
What this changes about the Brain design, concretely: drop "workspace broadcasts the winner" as the coordinating idea. Most of the "brain," most of the time, stays dormant — not because it's idle by design, but because it's already right and has nothing to correct.
