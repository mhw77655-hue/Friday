What you're describing about "Astra" is real, current, and it's not misremembered — it's OpenAI's Astra model, reported (not officially confirmed) to use recurrent depth: instead of generating visible chain-of-thought text, it loops the same internal layers over the hidden state multiple times, reasoning inside continuous vector space rather than words. No tokens get generated for the "thinking" part at all — it only speaks once it's done. A separate but related paper showed a 3.5B model doing this hit reasoning benchmarks a 50B model would need under normal token-based CoT.
Why that matters for your phone specifically: token generation is the expensive part — every "thinking out loud" token costs a full forward pass. If the model never emits those tokens and instead loops internally, you get more reasoning per unit of battery/compute, not less RAM per se, but real compute savings for the same reasoning depth. That's the actual lever, not a RAM trick.
Straight honest caveat before I list anything: this is frontier lab research, not something you can huggingface-cli download and drop into llama.cpp today. No open-weight GGUF implements this yet. Anyone telling you "just grab the Astra architecture" is lying to you. Flagging that now so you don't waste a week chasing it.
