## Codebase Patterns
- Source-text dump integrity should be verified programmatically (raw file content must be a byte-for-byte substring of the concatenated dump block) rather than by eyeballing.
- `git ls-files -s` shows mode 160000 for submodule gitlinks (directories, not files in the repo) — exclude them from any "tracked file" dump; they have no raw text content of their own.
- `file --mime-encoding <path>` classifies a file as us-ascii/utf-8 (text) vs binary; use `git ls-files -s | while read mode path; ` + that classifier to split a repo into text vs binary deterministically. Note `file` reports empty files as "empty" (not us-ascii) so empty tracked source files must be added by name.
- For line counts over paths with mixed slashes, prefer a `while read path; n=$(wc -l < "$path"); s=$((s+n))` loop over `sed`/`xargs wc -l`, which breaks when a path prefix contains the sed delimiter.
